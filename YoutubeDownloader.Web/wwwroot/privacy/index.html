Privacy Policy

Last updated: June 16, 2026

hmyut is a self-hosted application. When you run the web version on your own server or machine, you are the operator. This policy describes how the software handles data in typical use.

What we collect

The hmyut web app does not require user accounts and does not include third-party analytics or advertising trackers. The application processes YouTube URLs and search queries you submit in order to resolve video metadata and perform downloads.

Data storage

Downloaded files are stored on the server filesystem in a directory configured by the operator (the download root). Temporary processing files may also be created during conversion. Job status is kept in server memory while the application is running.

  • Video URLs and titles are used to display download progress in your browser.
  • Completed files remain on disk until the operator deletes them.
  • No data is sent to hmyut operators by default beyond what you submit for downloads.

Third-party services

To resolve and download videos, the server communicates with YouTube and related content delivery networks. Google Fonts may be loaded in the browser for typography if you use the bundled web interface. Operators can remove external font dependencies by self-hosting fonts.

Cookies

The web application does not set tracking cookies. Standard HTTP sessions are not required to use the downloader.

Your responsibilities

If you operate a public instance of this software, you are responsible for securing your server, complying with applicable laws, and informing your users how their data is handled. Only download content you have the right to access.

Contact

For questions about the open-source project, visit the GitHub repository.
