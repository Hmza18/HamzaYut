Common questions

Quick answers before you get started.

Is HamzaYut free?

Yes. HamzaYut is free and open source. You can host it yourself or use an instance someone else runs.

Do I need to install anything?

For the web app, just open it in a modern browser. The server needs FFmpeg installed (or it can auto-download it on first run).

Can I download playlists?

Playlist batch downloads are not supported yet. The web app currently handles single videos — playlist support is coming.

Is this affiliated with YouTube?

No. HamzaYut is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by YouTube or Google.

What about copyright?

Only download content you have the right to access. Respect creators' rights and YouTube's Terms of Service. This tool is for personal, lawful use.
